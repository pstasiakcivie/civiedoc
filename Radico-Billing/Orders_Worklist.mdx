# **Accessing the Order Worklist**

<Steps>
  <Step title="Navigate to the Order Worklist Section" icon="chevron-down">
    1. Click on the **Menu** **bar** **(≡)** located on the top left corner of the screen.
    2. From the **Menu** options, Click **Worklist** and select **Order Worklist**\
       This will take you to the main **Order Worklist** dashboard, where you can create worklists.
  </Step>
</Steps>

[**​**](https://radicobilling.mintlify.app/Radico-Billing/Coding#worklists)**Worklists**

In addition to the dashboard view, users can organize and manage records through dedicated worklists:

- **My Private Worklist:** A personalized list where users can maintain their own set of records for individual tracking and workflow management.
- **Shared Worklist:** A collaborative list where multiple users can access and work on records, enabling team-based users and shared accountability.

<Steps>
  <Step title="Enter Worklist Details">
    **Worklist Name**: Enter a name for the worklist in the **Worklist Name** field.

    **Select Category**: The category is by default set as **Order** when creating a new worklist.

  <Step title="Define Filter Conditions">
    Specify filter conditions to customize the worklist.

    Use **AND/OR Operators** to logically combine the conditions. Apply comparison **Conditions** such as **Equals**, **Contains**, or **Greater Than** to refine your results.

    ![3 Pn](/w7.png)

    **Grouping Filters with AND/OR Operators**

    You can group filters by selecting the **Group** **Item** icon to organise conditions using AND/OR operators.

    To add grouping to an AND/OR operation, follow these steps:

    1. Click the **\+** icon to add one or more filter conditions.
    2. Select the filter conditions you want to group using the provided checkboxes.
    3. Click the Group Item icon. The selected filter conditions will be grouped.
    4. To remove a condition from the group, click the **x** icon.

    ![2025 07 07 12 36 04 Pn](/15.png)
  </Step>
  <Step title="Preview Worklist">
    Click **Preview** to review the filtered results and ensure they meet the specified criteria.

    ![W6 Pn](/images/w6.png)
  </Step>
  <Step title="Save Worklist">
    Click **Save** to create the worklist for the selected category.
  </Step>
</Steps>

# **Managing the Worklist**

## **Previewing a Worklist**

Whether it’s a **Private** or **Shared** **Worklist**, users have the option to preview all associated records before getting started. Simply click the **Preview** icon located next to the relevant worklist to view its contents.

![Ow2 Pn](/ow8.png)

The **Preview** screen displays a list of coding records that match the filter conditions set during worklist creation.

## **Editing a Worklist**

Use this feature when you need to update or modify the details of an existing order worklist, such as its name, description, or assigned users. Follow the steps below to edit a worklist:

<Steps>
  <Step title="Open the Worklist for Editing">
    1. Click the **three-dot menu (︙)** next to the desired worklist name.
    2. Select **Edit** to make updates, if any changes are required.

    ![2025 07 08 15 16 19 Pn](/ow10.png)
  </Step>
  <Step title="Modify Worklist Name">
    Update the name to reflect any changes. Ensure the name remains descriptive and unique.

    ![Ow11 Pn](/images/ow11.png)
  </Step>
  <Step title="Update Description (Optional)">
    Edit or add information to define the worklist's scope or filtering criteria more clearly.
  </Step>
  <Step title="Change Privacy Settings">
    Toggle Mark as Private to restrict access to the current user only. Uncheck to allow sharing with other users.

    ![Ow12 Pn](/images/ow12.png)
  </Step>
  <Step title="User Group (For Shared Worklists Only)">
    This section becomes editable only when **Mark as Private** is unchecked.

    ![Ow20 Pn](/ow20.png)

    **Add Use**r: Search for and select users to include in the shared worklist.

    **Create/Edit User Group**: Organize users into groups for simplified sharing.

    **Allow Shared Users to Edit/Delete**: Enable this to grant edit or delete permissions to shared users.
  </Step>
  <Step title="Adjust Filter Conditions">
    Edit or add filter criteria by choosing a field (e.g., Approved At), an operator (e.g., Equals), and a value (e.g., Last 30 Days).

    Use **AND/OR** logic to combine multiple conditions as needed.

    ![15 Pn](/w7.png)

    1. Click the **\+** icon to add one or more filter conditions.
    2. Select the filter conditions you want to group using the provided checkboxes.
    3. Click the Group Item icon. The selected filter conditions will be grouped.
    4. To remove a condition from the group, click the **x** icon.
  </Step>
  <Step title="Preview Updated Records">
    Click **Preview** to view a list of records matching the updated criteria.
  </Step>
  <Step title="Save or Reset Changes">
    **Save**: Apply and store the updated changes.

    **Clear**: Discard all changes and revert to the original settings.
  </Step>

## **Delete Worklist**

Select this option to permanently remove a worklist that is no longer valid or required in the system.

Use the following steps to delete a worklist

<Steps>
  <Step title="Steps" icon="chevron-down">
    1. Click the **three-dot menu (…)** next to the worklist name you want to delete.
    2. Select **Delete** from the dropdown options.
    3. In the confirmation pop-up, click Yes to confirm and permanently delete the worklist.

    ![2025 07 08 15 16 19 Pn](/ow21.png)

    <Info>
      **Note**: Deleted worklists cannot be recovered. Make sure to double-check before confirming.
    </Info>
  </Step>
</Steps>

## **Hide a Shared Worklist**

If you want to keep a worklist but temporarily remove it from your active view, use the hide option without deleting the data.

<Steps>
  <Step title="Steps to Hide a Worklist" icon="chevron-down">
    1. Click the **three-dot menu (︙)** next to the shared worklist you want to hide.
    2. Select the **Hide toggle** to change its visibility status.
    3. The worklist will be hidden from the default view but is not deleted.

    ![2025 07 08 15 16 19 Pn](/f29.png)

    <Note>
      **Note:** Hidden worklists can be restored later using the appropriate filters or settings. No data is lost
    </Note>
  </Step>
</Steps>

## **View Hidden Worklists**

Choose this option to bring back a previously hidden worklist into your active view for continued use.

<Steps>
  <Step title="Steps to View Worklist" icon="chevron-down">
    1. Click the **View Hidden Worklist** toggle at the top of the worklist view.

    ![F30 Pn](/images/f30.png)

    2. This will display all worklists that are currently hidden.
    3. You can then unhide any shared worklist by using the same **three-dot menu (︙)** and toggle off the Hide option.
  </Step>
</Steps>

## **Unhide worklist**

Use this option to restore a previously hidden worklist so that it becomes visible in your active list again.

<Steps>
  <Step title="Steps to Unhide Worklist" icon="chevron-down">
    1. From the **Hidden Worklists view**, identify the worklist you want to restore.
    2. Click on the **three-dots (⋮) menu** next to the worklist.

    ![Ow22 Pn](/images/ow22.png)

    3. Select the **Unhide** option from the menu.
    4. The worklist will now reappear in your active view.
  </Step>
</Steps>

# Default Shared Worklists

The **Ordering Worklist** includes the following default shared worklists: **Missing Ordering Doctors, Missing Modality, Missing Date of Service, Missing Reading Doctors,** and **Missing Reading Locations**. Each worklist highlights records missing specific information.

The interface is split into two panels:\
The **left panel** displays records with missing fields and provides input fields to fill in the data. \
The **right panel** shows the corresponding document or report, allowing you to review the content and update the missing details accordingly.

![2025 07 08 16 59 35 Pn](/ow23.png)

## **Missing Ordering Doctor**

The **Missing Ordering Doctor** worklist helps users resolve records that lack an assigned ordering physician.

<Steps>
  <Step title="Open the Missing Ordering Doctor Worklist">
    Click the **Preview** icon next to the \*\*Missing Ordering Doctor \*\*worklist to view all records missing ordering doctor information.

    ![Ow24 Pn](/images/ow24.png)
  </Step>
  <Step title="View Split Screen Layout">
    The screen is divided into two panels:

    <img
      src="/images/ow25.png"
      alt="Ow25 Pn"
      title="Ow25 Pn"
      className="mx-auto"
      style={{ width:"88%" }}
    />

    - **Right Panel**: Displays the associated report for the selected record.
    - **Left Panel**: Provides the interface to assign the **Ordering Doctor** by selecting an NPI from the dropdown.
  </Step>
  <Step title="Filter and Export Functionality">
    Use the **Filter Panel** to refine the list based on the following filters: **Accession Number, Procedure Description, Client Name, Doctor First/Last Name**, and **Mapped/Unmapped** Status.

    ![Ow26 Pn](/images/ow26.png)

    <Tip>
      Use the **Mapped/Unmapped** status filter to quickly identify records that still need doctor assignment.
    </Tip>
    Click the **Export** button located next to the Filter panel.

    ![Ow27 Pn](/images/ow27.png)

    The export will include only the records currently visible based on the applied filters. It supports **pagination**, so only the data shown on the current page will be exported. The exported file maintains the same **top-down format** as displayed in the UI, ensuring consistency and readability.
  </Step>
  <Step title="Review the Report">
    Select the desired record from the list. The corresponding report opens in the right-hand panel.

    <img
      src="/images/ow28.png"
      alt="Ow28 Pn"
      title="Ow28 Pn"
      style={{ width:"94%" }}
    />

    Within the report panel, the user has the following options:

    **Zoom In / Zoom Out** – Adjust the report size for better readability.

    **Download** – Save a copy of the report to your device.

    **Open in Separate Window** – View the report in a larger, dedicated window.

    **Rotate** – Change the orientation of the report for easier viewing.
  </Step>
  <Step title="Assign Ordering Doctor">
    Begin typing the ordering doctor name as identified from report displyaed in the right panel. The system will **auto-suggest** matching values. Select the correct ordering doctor from the dropdown.

    If the doctor is not listed in the suggestions, click the **Add Doctor (\+)** icon to manually enter new doctor's information.

    <img
      src="/ow29.png"
      alt="1 Pn"
      title="1 Pn"
      className="mx-auto"
      style={{ width:"70%" }}
    />

    1. Clicking the **\+** icon in the left panel opens the **Ordering Doctor** pop-up in the right panel, just below the report section, allowing you to enter the doctor’s **NPI** details.
    2. The system automatically retrieves and populates the doctor’s details from the **NPI Registry**.
    3. Once the details are verified, the doctor is added to the system.
    4. The newly added doctor is then mapped to the selected record.
  </Step>
  <Step title="Save and Confirm">
    Once an Ordering Doctor is selected or added, the record is **automatically saved**.\
    A confirmation toast will appear: **Record saved successfully.**

    <Note>
      Click the **Refresh (⟳)** button to reload and update the worklist with the latest data.
    </Note>
  </Step>
</Steps>
