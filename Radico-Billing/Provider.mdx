# **Accessing Provider module**

**Search**: Use the **Search** **Bar** at the top of the provider list to quickly locate providers by **Name**, **NPI**, **Email**, and **Phone**.

**Filter**: Use **Filter** options to refine the list based on provider **Type** and **Status**.

**Status**: Activate or Deactivate a provider using the toggle under the Status column.

# **Adding a Provider**

To add a new provider click the **Add** button at the top right corner of the Provider module. It allows users to manually register a new healthcare provider into the system with detailed information.

![Picture1 Pn](/p2.png)

Follow the steps below to add a new provider to the system:

<Steps>
  <Step title="Enter Provider Details">
    **Type and NPI**

    **Type (Required)**: Select the provider type from the dropdown list (such as Locum Provider, Reading Doctor and Supervising Doctor).

    **NPI (Required)**: Enter the provider’s National Provider Identifier.

    <img
      src="/p3.png"
      alt="+newappointment Pn"
      title="+newappointment Pn"
      style={{ width:"69%" }}
      className="mx-auto"
    />

    <Note>
      **Note**\
      Once the NPI is entered, the system auto-fetches and populates the following fields from the NPI Registry - First Name, Last Name, Middle Name (if available), Degree, License Number, Effective Date, Terminated Date and Taxonomy Code.

      ![15 Pn](/images/p4.png)
    </Note>
  </Step>
  <Step title="Dates and Location (In case of provider type as Reading Doctor)">
    **Default Location** (In case of provider type as Reading Doctor): Select the provider’s default practice location from the dropdown.

    <img
      src="/images/p9.png"
      alt="P4 Pn"
      title=""
      style={{ width:"100%" }}
    />
  </Step>
  <Step title="Enter Address Information">
    **Address 1 (Required)**: Enter the provider’s address.

    **Address 2 (Optional)**: Enter provider’s address details.

    ![P5 Pn](/images/p5.png)

    **City (Required)**: Enter the city.

    **State (Required)**: Enter the state.

    **ZIP Code (Required)**: Enter the ZIP code.
  </Step>
  <Step title="Enter Contact Details">
    **Phone**: Enter the provider's contact number in the format (999) 999-9999.

    ![P6 Pn](/images/p6.png)

    **Email**: Enter the provider’s email address.
  </Step>
  <Step title="Set Provider Status">
    **Active**: Toggle the switch to indicate if the provider is currently active or not.

    ![P7 Pn](/images/p7.png)

    **Teaching Physician**: Toggle if the provider is designated as a teaching physician.
  </Step>
  <Step title="Save or Cancel">
    Click**Save**  to add the new provider.

    Click**Cancel**  to discard the changes.
  </Step>
</Steps>

# Editing a Provider

This form appears when a user clicks the **Edit** icon next to a provider record. It allows authorized users to update selected fields for an existing provider.

<Steps>
  <Step title="Open the Edit Provider Form">
    Click the **Edit** icon next to the provider you want to update. The edit form will open with the provider’s existing details populated.

    ![P19 Pn](/images/p19.png)
  </Step>
  <Step title="Update Type and Location">
    **Type (Required):** Select and update the provider type (e.g., Locum Provider, Reading Doctor, Supervising Doctor).

    ![15 Pn](/p8.png)

    **Default Location:** Update the default location (applicable for Reading Doctors).

    ![15 Pn](/images/p9.png)

    <Note>
      The following fields cannot be edited for existing providers: NPI, First Name, Last Name, Middle Name, Degree, License Number, and Taxonomy Code. These fields are system-controlled to maintain data integrity.
    </Note>
  </Step>
  <Step title="Update Address">
    ![15 Pn](/images/p10.png)

    **Address 1 (Required):** Update the primary practice address.

    **Address 2 (Optional):** Provide additional address details, if applicable.

    **City, State, ZIP Code:** Ensure all three fields are filled in correctly.
  </Step>
  <Step title="Update Contact Details">
    ![15 Pn](/images/p11.png)

    **Phone:** Edit the contact number if required (use format: _(999) 999-9999_).

    **Email:** Update the provider’s email address.
  </Step>
  <Step title="Toggle Provider Status and Teaching Designation">
    **Active:** Toggle this ON or OFF to set the provider's active status.

    **Teaching Physician:** Toggle ON if the provider holds a teaching designation.

    ![15 Pn](/images/p12.png)
  </Step>
  <Step title="Save or Cancel Changes">
    Click **Save** to apply all updates.

    Click **Cancel** to discard changes and return to the previous screen.
  </Step>
</Steps>

# **Credentialing**

The **Credentialing** feature in the **Provider** module ensures that providers are verified, enrolled, and payer-approved, enabling their services to be billed and reimbursed without denials. Until a provider is successfully enrolled with the corresponding carrier groups, their claims will remain on hold. This feature also allows users to add, edit, or delete provider credentials as needed.

![Picture4 Pn](/p13.png)

This page appears when the user clicks the **Credentialing** icon besides the Provider whose credentials are to be added.

**Filter**: Click the **Filter** button to narrow down the results by **Provider**, **Date Range**, or **Carrier**, **Start Date**, **End Date**, **Assigned To**, and **Status.**

**Add**: Click **Add** to create a new credentialing record for a provider.

**Edit**: Use the **Edit** icon to update credentialing details.

**Delete**: Use the **Delete** icon to remove a credentialing entry.

## **Add Credentialing**

This page appears when the user clicks the **Add** button on the **Credentialing** page. It allows the user to create a new credentialing record for a selected healthcare provider by entering required provider, carrier, and location details.

![Picture5 Pn](/p14.png)

**Steps to Add Credentialing**

<Steps>
  <Step title="Provider NPI (Auto-filled)">
    Automatically displays the National Provider Identifier linked to the selected provider.

    ![P15 Pn](/images/p15.png)
  </Step>
  <Step title="Provider Name (Auto-filled)">
    Displays the full name of the selected provider.
  </Step>
  <Step title="Start Date & End Date">
    Select the start date when the credentialing process is initiated.

    Select the End date expected or actual date of completion.
  </Step>
  <Step title="Carrier Code & Carrier Name">
    Choose the insurance carrier code from the dropdown list. It auto populates the Carrier Name corresponding to the selected carrier code.

    <img
      src="/images/p24.png"
      alt="P24 Pn"
      title="P24 Pn"
      className="mx-auto"
      style={{ width:"84%" }}
    />
  </Step>
  <Step title="Assign To & Status">
    To assign a record, use the **Assign To** field and select the appropriate credentialing user from the dropdown list.

    <img
      src="/images/p20.png"
      alt="P20 Pn"
      title="P20 Pn"
      className="mx-auto"
      style={{ width:"91%" }}
    />

    The credentialing record is assigned to a credentialing user from the Operations team, who is responsible for reviewing the details and completing the enrolment of the provider’s credentials with the corresponding carrier groups. 

    Choose the **status** of the credentialing from the dropdown (e.g., **In Progress**, **Pending** and **Completed**).
  </Step>
  <Step title="Reading Location Code & Reading Location Address">
    Select the **Reading** **Location** **Code** that identifies the reading location where the provider practices. **Reading Location Address** is auto filled according to selected reading location code.

    <img
      src="/images/p25.png"
      alt="P25 Pn"
      title="P25 Pn"
      className="mx-auto"
      style={{ width:"94%" }}
    />
  </Step>
  <Step title="Save & Cancel">
    Click **Save** to add the new credentialing record or click **Cancel** to exit without saving any changes.
  </Step>
</Steps>

## **Delete Credentialing**

User can delete an existing credentialing record by clicking the **Delete** icon located in the **Action** column of the credentialing list.

<Steps>
  <Step title="Delete">
    Locate the record you wish to delete. Click the **Delete** icon under the **Action** column.

    <img
      src="/images/p17.png"
      alt="P18 Pn"
      title="P18 Pn"
      className="mx-auto"
      style={{ width:"89%" }}
    />

    A confirmation popup appears with the message: **Are you sure you want to delete this credentialing?**
  </Step>
  <Step title="Confirm ">
    Click **Yes** to proceed and permanently delete the credentialing record or click **Cancel** to abort the action and keep the record intact.

    <img
      src="/images/p18.png"
      alt="P18 Pn"
      title="P18 Pn"
      className="mx-auto"
      style={{ width:"37%" }}
    />

    <Note>
      **Note:**

      Deleted credentialing records cannot be recovered. Ensure the information is no longer needed before confirming the deletion.
    </Note>
  </Step>
</Steps>
